# 🚀 Shilish Reddy Dokuri — Personal Portfolio

> **CSE Graduate · Full-Stack Web Developer · Data Analyst · Python Engineer**

A modern, interactive personal portfolio website built with vanilla HTML, CSS, and JavaScript — featuring 3D tilt effects, Three.js canvas animations, glassmorphism UI, and role-specific resume downloads.

🔗 **Live Portfolio:** [View Here](https://github.com/dokuri/personal-portfolio)

---

## ✨ Features

- **3D Interactive Hero** — Three.js constellation/particle canvas background with live animation
- **3D Tilt Cards** — Mouse-tracking perspective tilt on project, skill, resume, and experience cards
- **Glassmorphism UI** — Frosted glass card aesthetics with subtle glow effects
- **Skills Filter** — Dynamic category filtering across 10+ technical skills
- **Interactive Timeline** — Animated internship experience section
- **Project Modals** — Deep-dive detail overlays for each featured project
- **Role-Specific Resumes** — Three tailored PDF resume downloads (Web Dev / Data Analyst / Python)
- **Certifications Gallery** — Filterable credential cards with verification links
- **Dark Mode First** — Premium dark theme with teal accent color system
- **Fully Responsive** — Mobile-first layout with a custom drawer navigation
- **Smooth Scroll & Animations** — Intersection Observer-powered fade-in animations

## 🚀 Getting Started

This is a **pure static site** — no build tools or dependencies required.

```bash

git clone https://github.com/dokuri/personal-portfolio.git

# Navigate into the folder
cd personal-portfolio

# Open in your browser
# Simply open index.html in any modern browser
# OR use VS Code Live Server for hot-reload:
# Right-click index.html → "Open with Live Server"
```
